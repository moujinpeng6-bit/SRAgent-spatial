# 首次 GEO 留出评鉴

参考样本在运行前固定于 `c88b7b7`，未在开发版本的测试、示例和文档中使用。系统只收到自然语言任务。运行结束后，评鉴程序才用样本编号对照参考标签。此次标签依据 GEO 发布者的样本记录暂定，等待独立研究者复核。

每条任务最多读 5 项 GEO 研究、每项最多展开 4 个样本。单候选下载上限为 16 MiB。模型为 DeepSeek Flash。三项任务并行运行。耗时为各任务实际经过的时间，费用按记录的 token 和公开的峰值、未缓存费率估算。[模型费率](https://api-docs.deepseek.com/quick_start/pricing/)

参考集内召回率为 25%。漏掉的三个人乳腺癌样本没有进入候选。三个人结肠癌样本被找到，但样本中的 `colon cancer` 没有匹配解析后的 `colorectal cancer`。候选数量、GEO 检索排序和样本展开上限都会影响这个数。

7 个纳入样本中有 5 个未列入冻结参考集。事后查阅其 GEO 记录，4 个乳腺癌样本的诊断和平台符合任务，1 个皮肤样本由病例和健康对照共同组成，整张切片被误收为健康。事后核对不回填冻结分数。对全部 7 个结果的判断仍待研究者复核。[事后核对记录](posthoc.md)

7 个样本均取得部分空间文件，缺失的表达文件在本次试验中超出预算。原始日志把随后误触发的验证记录为 `validation_error`，保留在基线结果中。本次提交已修复缺件原因被覆盖的问题，并补上结肠癌别名及有条码级分组证据的混合样本筛选。用发布者原始记录复查，三条结肠癌被纳入，混合皮肤样本被排除，另外四条乳腺癌样本保存了各自的 BioStudies 图像链接。原参考集已经用于定位问题。修正后的完整流程应使用新的留出集验收。[分类与图像链接复查](followup.json)

另做一次独立的补件实测。复用 GSM10144987 的图像、坐标与比例文件，从 GEO 补取 26,139,723 字节的完整 HDF5 表达矩阵，耗时 245.38 秒。4,992 个表达条码都有坐标，映射到 600 × 600 图像后无越界，完整矩阵 23,389,204 条计数通过结构检查。这条结果单列，原留出评鉴保留原始预算和得分。[补件与验证报告](file_followup.json)

研究者可先依据 [样本复核表](review.md) 独立判断每条样本，再与 [暂定参考标签](reference.json) 和 [机器逐样本结果](summary.json) 比对。当前数字反映这次 GEO 小规模运行。
