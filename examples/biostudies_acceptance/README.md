# BioStudies 无 BigQuery 验收（2026-11-06）

本轮使用官方公开 API，输入物种、组织和平台搜索；没有在命令里预先指定研究编号、样本 ID、文件 URL 或目录快照。大文件保留在本地 E 盘，仓库仅保存清单、检查结果和来源。

| 切片目录 | 表达位置 | 表达特征 | 完整读取的计数条目 | 图像 | 越界 |
|---|---:|---:|---:|---|---:|
| V10T03-279-B1 | 4,034 | 36,601 | 8,180,705 | 600 × 581 PNG | 0 |
| V10T03-279-C1 | 4,882 | 36,601 | 10,281,590 | 600 × 581 PNG | 0 |

合计 8,916 个位置、18,462,295 条计数。每张切片核对表达条码、位置表、比例因子及完整 PNG 解码，同时读取完整 HDF5 CSC 数组检查索引、列指针和非负整数计数。样本物种和组织来自发布者 `hs_visium_metadata.tsv`，按样本 ID 对应 ZIP 目录，保存来源和 SHA-256。图像位置由全分辨率像素坐标乘以发布者的 0.05 比例因子得到，没有推断微米比例。

同一研究还有其他切片，本轮只处理约定的前两张；未处理目录在 JSON 中列出。两张通过是文件数值对应通过，不是病理精细配准、分割金标准或生物学质量评价。

## 下载、中断和模型

官方 ZIP 约 1.09 GB，通过 Range 只读取所需分段，没有下载完整归档或原始高分辨率大图。下载中在第一份完整 HDF5 已校验后实际终止运行进程，然后恢复。该矩阵在后续运行中哈希及修改时间均不变。

最后另做一次禁止任何 API/文件 HTTP 请求的缓存续跑：两张切片仍通过；8 个配套文件的哈希和修改时间全部不变，HTTP 尝试为 0。见 [续跑与中断证据](resume_evidence.json)。这验证固定来源版本的缓存重放，不代表离线取得最新官网内容。

早期分段请求出现超时。诊断中同一官方区间返回 HTTP 206、正确范围和相同 ETag，响应等待约 32 秒，超过原来 25 秒上限；新来源改为 90 秒，并采用限次重试和最大 4 MiB 合并预取。已校验的文件继续复用。

DeepSeek `deepseek-flash` 分别真实调用肺和肝任务的 BioStudies 工具一次。模型读取实际状态；程序计算文件对应结果。只开放本轮来源工具，没有声称跑了原版总控所有模块。
