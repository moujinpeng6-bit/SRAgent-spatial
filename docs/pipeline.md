# v0.6：同一样本从 GEO 搜索到空间核查

2026-11-03 已用人类肺组织 Xenium 样本 GSM7990538 / GSE250346 完成一次真实流程，原版 SRAgent 总控使用 DeepSeek `deepseek-flash`。总耗时 38.89 秒，`agent_pipeline_verified=true`。

101 项离线测试和依赖一致性检查通过，覆盖跨样本链接、多个同名包、未完成下载、非法成员路径、错误执行顺序、假完成、自动登记和空间核查；低分辨率结果图已查看。离线测试使用固定服务选择以避免本机模型环境影响替身图，不会调用真实模型。

## 本轮补上的连接

此前需要人手在 manifest 中填写表达目录、图像路径和压缩包内部目录。本轮 `pipeline` 不接收手写 manifest，只指定目标研究、样本和已有资料的搜索根目录。

1. **实时搜索**：构造 Homo sapiens + lung + Xenium + 指定 GSE 的 Entrez 查询。确认目标研究确实在 esearch/esummary 结果中，不用直接读取某个 GSE 代替搜索。
2. **样本归属与筛选**：研究列出的 GSM 必须包含目标；GSM 自身也须回链该 GSE。读取样本自己的组织、物种和实验资料，规则和真实模型结果均符合才继续，引用须能在该 GSM 的原文中找到。发送模型的筛选字段排除了年龄、性别等人口学属性。
3. **自动定位文件**：从 GSM 自己的 supplementary_file 字段确定唯一 tar.gz 链接，拒绝跨样本 URL、多包歧义和任意外部主机。递归盘点资料根目录，精确匹配该文件名，不接收模型生成的路径，也不选择 `.part`。多个完整同名候选须人工解决，不能任选一个。
4. **自动准备与登记**：流式读取压缩包，仅提取同一 outs 目录的实验说明、细胞表、矩阵、焦平面图像，以及存在时的细胞/细胞核边界。核对 GSM 根目录及实验 region_name 与样本标题，再自动生成 manifest。
5. **实际空间验证**：通过已有验证器读取刚准备的文件，核对 ID、计数、µm 单位、图像范围和边界，计算几何区域及邻居，保存报告、细胞索引和预览图；另核对原始包内成员哈希。

总控四个实际工具依次为 `search_pipeline_study`、`screen_pipeline_sample`、`prepare_pipeline_files`、`validate_pipeline_sample`。完成状态由上述实际处理结果及工具调用顺序共同决定；模型最终文字不能补造完成。

## 本次真实结果

详见 [公开运行摘要](../examples/lung_pipeline/run_summary.json)。GEO 本次目标查询命中 1 项研究，研究列出 45 个样本，本次明确只处理 GSM7990538，其余 44 个不属于本次任务。

- 自动从 GEO 样本页获取了原始包链接，并在 E 盘自动找到了完整同名压缩包。
- 复用原始包 932,744,371 字节；本次下载原始数据字节数为 0。网络读取的是实时 GEO 元数据。
- 从该包自动准备 6 个文件，共 68,022,330 字节，并重新生成路径登记表；未借用上一轮提取文件或手工登记表。
- 12,578 个细胞、343 个基因表达特征，19 项对应检查全部通过。
- 半径 150 µm 的几何演示区域包含 417 个细胞；不是病理标注。
- E 盘原始文件未修改，图像和矩阵未上传到模型或 GitHub；模型使用公开筛选证据及用户已授权的核查摘要。

本地包与 GEO URL 的关联依据是样本所属链接、精确文件名、内部 GSM 根目录、实验区域和实际哈希记录。没有从远端重新读取整个原始包或取得官方校验和，因此不能宣称已证明本地包与当前远端包逐字节相同。验证器证明的是本地表达/图像等文件与该本地原始包成员一致。

## 运行

安装既有 agent、xenium 可选依赖，在本机配置模型凭证。无需 Google Cloud。

```powershell
python run.py pipeline --study GSE250346 --sample GSM7990538 --archive-root E:/Xenium --model deepseek-flash --out outputs/lung_pipeline_v06/live
```

输出包括：实时 metadata_cache、研究与样本字段、screening.json、prepared 下的配套文件、auto_manifest.json、validation 下的空间核查及 run.json。

每次使用新的输出目录，避免把旧提取文件或半成品算作本次成功。默认下载预算为零，优先复用本地完整原始包；找不到时明确失败。可用 `--download-mib` 设置最高 2048 MiB 的单包下载预算，来自该 GSM 的固定 HTTPS 链接，受大小和完整性检查约束。**本轮真实验证的是本地包自动复用路径，未真实验证大包重新下载路径。**

## 边界与后续

这是一项**指定研究、指定样本的人类肺 Xenium 流程验证**，不能称为无约束搜索已经自动发现所有数据。当前仍要求用户指定目标 GSE/GSM 和本地资料根目录；没有实现全库候选批量调度、任意网站解析、多个包的自动消歧或所有空间平台适配。

现有代码继续保留 GEO 广义空间候选搜索和 GSM 批量筛选；下一步可让其符合样本逐一进入本轮新接好的文件准备阶段，并逐样本记录失败、缺失和完成状态。其他组织的通用化、Visium 统一验证接口、病理图像配准和独立留出评价也尚未完成。
