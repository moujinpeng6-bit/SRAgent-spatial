# 开发路线

所有任务初始均未完成。以下是计划和验收要求。

## M0：仓库与规范

- [ ] 核对 README、字段及试点范围。
- [ ] 确定来源与排除标准。

## M1：第一个真实检索闭环

- [ ] 实现 GEO 候选检索，并记录实际查询条件、日期和结果编号。
- [ ] 读取研究与样本说明，保存来源及公开文件链接。
- [ ] 输出 5–10 条人类肺组织相关 Visium 候选记录，允许结果不足并如实报告。
- [ ] 人工核查空间技术、组织、表达与坐标的公开情况。
- [ ] 导出符合字段定义的 CSV / JSON。

验收：真实来源可打开，字段有证据，重复项有说明，缺失项不被补造成事实。暂不下载大图或全量测序文件。

## M2：资料提取自动化

- [ ] 建立人工核查集，分别评价字段取得率与正确率。
- [ ] 比较直接字段读取、规则提取和可选语言模型辅助提取。
- [ ] 保存未知、冲突与失败原因，加入限速、缓存和重试。

## M3：空间文件校验

- [ ] 对少量公开资产检查 ID、坐标单位、切片与参考系。
- [ ] 检查图像变换，并抽样叠图核查。
- [ ] 记录处理、分割和标注版本。

## M4：扩展与维护

- [ ] 增加 Xenium 等平台和官方来源适配。
- [ ] 加入增量更新、来源去重和处理日志。
- [ ] 根据研究问题设计下游评价；数据重处理和模型训练另行立项。
