# 开发路线

## 最新进度：v0.6（2026-11-03）

当前阶段是“指定目标的真实空间数据流程已贯通，准备扩展批量候选”。Google Cloud / BigQuery 暂缓不影响此流程。

| 环节 | 已完成及证据 | 剩余边界 |
|---|---|---|
| 模型和原版总控 | 已有 DeepSeek 真实调用，复用固定上游总控和子 Agent | 不是所有上游模块均在线验证 |
| GEO 搜索与样本核查 | 已有空间候选查询、GSM 展开、逐样本证据核对；此前 31 个 Visium GSM 元数据完成 | 完整判断器仍限定人类肺组织 |
| 本地空间验证 | Xenium 真数据、19 项文件对应检查；v0.5 已有真实 Agent 调用 | Visium 尚未统一进入同一工具接口 |
| 搜索到文件的连接 | v0.6 从同一 GSM 的补充链接确定原始包，自动盘点本地文件、提取配套材料并生成 manifest | 目前指定 GSE/GSM，不是对全部候选自动批处理 |
| 同一样本完整真实流程 | GSE250346 / GSM7990538，四个工具依次执行，38.89 秒；4 个实时 GEO 请求、0 个缓存请求；19/19 检查通过 | 研究列出 45 个样本，只处理明确选定的 1 个 |
| 文件取得 | 自动复用 E 盘完整原始包约 933 MB；提取 6 个文件共约 68 MB | 新增受预算限制的下载代码，本轮未真实重新下载大包；远端字节身份未核对 |
| 核查与复现 | 101 项离线测试通过，依赖检查通过；保留来源、哈希、调用和失败状态 | 不是独立生物学准确率、召回率或分割金标准 |

完整证据与命令：[同一样本流程](pipeline.md)、[公开运行摘要](../examples/lung_pipeline/)、[v0.5 验证工具](local_validation_agent.md)。图像、矩阵和细胞级索引留在本地。

### 下一步顺序

1. 把已有候选筛选结果逐一交给新文件准备阶段，扩展少量真实样本，记录缺失、受限、失败及可恢复状态。
2. 对可访问公开资产验证下载路径，并完善多包消歧、批量任务与文件准备阶段的断点续跑。
3. 统一 Xenium / Visium 验证入口；分别处理 cell、spot、bin 和不同文件版本。
4. 将组织判断从肺试点参数化，再建立经过研究者复核的独立测试集和原版/空间版本对照。
5. 条件允许时补 BigQuery、术语向量库及更多上游模块；不作为当前空间流程前提。
