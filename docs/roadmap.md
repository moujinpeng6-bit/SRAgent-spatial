# 开发路线

### v0.15 研究任务续跑与首次留出评鉴（2026-11-07）

`research-spatial` 记录论文标识、研究、样本或切片、图像来源和文件哈希。可在同一输出目录恢复任务。实测中断后两张肺 Visium 切片均完成，已通过文件未重写、数据源新增请求为零。跨来源只有完整文件指纹一致时才标记重复，图像或论文编号可供追溯。见 [续跑记录](../examples/research_resume/acceptance.json)。

初次 GEO 留出评鉴覆盖三项任务和 12 个冻结样本。8 个参考阳性中纳入 2 个，漏收 6 个。已纳入的 7 个样本均有文件超出试验下载限额，0 个配齐。事后核对另发现 1 个混合样本误收，已补混合样本与疾病别名规则。额外选 1 个入选乳腺癌样本，复用图像和坐标，补下表达矩阵后 4,992 个条码与完整计数通过。研究者独立复核、修正后的新留出集评鉴及扩大样本量后的配齐率仍待完成。BigQuery 保持停用。见 [评鉴与复核表](../examples/independent_evaluation/)。

### v0.14：研究条件、样本疾病、多来源平台和文件准备（2026-11-06）

前四项开发目标接入 `research-spatial`：DeepSeek 提取自然语言条件；样本级疾病/肿瘤/正常/癌旁/混合/未知证据控制纳入；GEO、BioStudies、10x 共用三个子 Agent 的细分工具；增加安全 TAR/ZIP、完整 MTX/HDF5、gzip、独立附件、官方外部清单及显式跨包配对。

真实综合胰腺癌任务记录 11 条结果，5 条入选，1 套 Xenium 的 190,965 个细胞通过 12 项检查，2 条受预算限制、2 条缺件，其他未纳入。健康胰腺被排除；仅 10x 缓存零新增数据下载的另一轮也通过。同一新入口还通过两张肺 Visium 和一套心脏原生 2 µm HD。HD 本轮矩阵仅检查头部；2/16 µm 分离另有合成文件测试。缓存未覆盖的 10x 平台与官网实时限制明确记录，不声称全库实时发现。144 项测试通过，依赖检查通过。

完整说明与边界见 [四项改进](research_spatial.md)和[逐条验收](../examples/research_acceptance/)。

### v0.13：总控与三个模型子 Agent（2026-11-06）

已把 BioStudies 大工具拆为查询、研究证据读取、文件清单、准备和验证工具。DeepSeek 总控分别委派搜索、文件、验证子 Agent。普通缓存轮次完成 10 次工具操作；实时元数据与受控故障轮次发生 7 次官方请求、15 次工具操作，总控根据缺件状态返回文件子 Agent 补件，再次验证。两轮均有两张真实肺 Visium 切片通过，一项不支持格式保留失败状态。受控超时和删件在新建副本上执行，来源及日志明确标注。详见 [多 Agent 说明](multiagent.md) 和 [逐项验收](../examples/multiagent_acceptance/)。尚未声称原版全部上游模块已在该总控中在线验收，或已经完成多 Agent 会话断点恢复。

### v0.12：不用 BigQuery 的官方公共搜索入口（2026-11-06）

新增 BioStudies / ArrayExpress 官方 REST API，接入 `find-spatial --source biostudies`。输入物种、组织和平台即可查询研究，读取物种/组织/平台证据，从官方登记文件定位 Space Ranger ZIP，准备同目录的表达、坐标、比例因子和低分辨率图像，并调用平台验证器。不是 BigQuery SQL 的等价实现，也不依赖 10x 官网浏览器验证。

新增完整 HDF5 稀疏计数数组检查，保留条码、坐标、图像边界和解码检查。分段下载保存来源、长度、强 ETag、哈希，续跑重新验证本地已通过文件；支持限次重试、每条候选独立失败、CSV 清单及 DeepSeek 限定工具入口。在线实测与模拟缺件/错配测试分别记录在 [本次验收](../examples/biostudies_acceptance/)。使用方式见 [BioStudies 说明](biostudies.md)。

实时人肺 Visium 检索读取 3 项研究，排除小鼠研究并记录不支持的 TAR 布局；S-BSST1410 的两张切片实际配齐并通过，合计 8,916 个位置、18,462,295 条完整计数。实际中断后恢复，首份矩阵哈希和修改时间保持一致；另一次禁止 HTTP 的续跑中 8 个配套文件全部保持不变、2 张切片仍通过。DeepSeek 实际调用新来源工具。肝脏 Xenium 和肾脏 HD 查询的未通过/不支持结果也保存。129 项测试与依赖检查通过。

仍需独立完成的工作：新来源的任意 TAR/独立文件/外部大清单自动配对、跨来源同一样本去重、更大规模独立留出评价，以及图像内容和病理精细配准。10x 实时目录仍受官方访问验证限制，现有快照模式继续明确标记。BigQuery 暂缓；这些限制不会被报告为已通过。

### 跨组织批量验收、完整矩阵和 Agent 对照

GEO 批量命令支持复用本地附件和检查远端链接。续跑保留已通过结果并重试缺件或访问失败的样本。Visium HD 按完整的同前缀文件组独立核查切片，缺件和歧义逐组记录。Xenium 样本没有归档时报告独立发布的配套角色。10x 实时访问失败时可显式回退到目录快照，并保留实时错误。

三项 GEO 新查询返回 11 个样本候选，6 个入选。入选的肝脏 Xenium 附件缺实验描述文件，小鼠脾脏 Visium 缺坐标或比例因子，脾脏 Visium HD 的多个表达文件组与共用空间附件之间缺少可确认的一一对应。两项公开参考研究中，脾脏研究进入本次查询前三项，肝脏研究未进入。见 [逐样本验收](../examples/cross_tissue_acceptance/geo_batch.json)。

使用 E 盘官方心脏归档缓存提取完整矩阵，检查 43,776,546 条计数记录，索引及整数计数均有效。将 4,000 个组织内位置抽样叠加到低分辨率图像并检查整体布局。报告保留完整矩阵哈希和核查范围。见 [完整矩阵验收](../examples/cross_tissue_acceptance/heart_full_matrix.json)。

六个公开 GEO 样本的暂定参考标签和证据已固定，供研究者复核。明确 Agent 输出字段类型后，规则、原版 NCBI Agent 和空间 Agent 分别与参考标签一致 4、6、6 条。三种方法均选中了 4 条应纳入的样本，本组未观察到错误纳入。另用原版 Entrez 搜索组件运行同组三项检索，报告保存工具执行记录和待核实的生成内容。样本来自同轮检索结果，比较范围限于该批样本。见 [对照材料及结果](../examples/cross_tissue_acceptance/)。

### 10x 人心脏目录与空间验收（2026-11-04）

使用 `find-spatial --source 10x --10x-interactive` 从 E 盘空目录发起「人类、心脏、Visium HD」实时查询。用户在命令打开的 Chrome 中看到 Vercel「无法验证您的浏览器，代码 10」，页面未提供可操作的验证控件。该次验收在目录访问阶段结束，报告为 `access_failed`，尚未进入下载和空间验证。普通 Chrome 可由用户正常打开目录并看到候选。交互模式保留同一次运行等待人工验证的能力，并对明确的代码 10 返回单独的错误说明。

查阅 10x 公开数据目录和官方命令行文档后，尚未找到可用于实时查询该目录的公开官方 API。Cloud CLI 文档列出的查询与下载用于账户内的项目和分析文件。本次采用官网目录快照记录样本和归档链接。参见 [10x 公开数据目录](https://www.10xgenomics.com/datasets)、[10x Cloud CLI 文档](https://www.10xgenomics.com/support/software/pipeline-runner/latest/tutorials/CA-cloud-cli-documentation-for-windows)。

在 E 盘新目录从快照筛出 1 个健康人心脏 FFPE、6.5 mm 捕获区样本。命令行与同版本分段预取共同完成下载，验证读取 1,090,519,040 字节归档前缀。原生 2 µm 的 10,615,406 个表达条码全部在坐标表中，数量与矩阵头一致，映射到 478 × 600 的低分辨率图像后无越界。仓库记录实时失败报告、快照通过报告与验证文件的 SHA-256。见 [样本与报告](../examples/tenx_heart_acceptance/)。

### 10x 人扁桃体目录验收（2026-11-04）

独立命令行浏览器访问 10x 官网目录时收到 HTTP 429 浏览器验证页。命令行现在记录明确的访问失败原因。另加目录快照入口 `--10x-catalog-snapshot`，用物种、组织和平台筛选浏览器采集的公开目录记录，仅接受 10x 官方数据集与归档链接。批量报告分别标记 `live` 和 `snapshot`。见 [在线访问结果和目录来源](../examples/tenx_tonsil_acceptance/)。

从 E 盘空目录运行快照模式，选出一项新的人扁桃体 Visium HD 3′ 样本。命令行和同一归档版本的并行分段预取共同完成下载，读取 1,853,882,368 字节归档前缀。原生 2 µm 的 8,689,797 个表达条码全部有坐标，数量与矩阵头一致，映射到 422 × 600 的低分辨率图像后无越界。验收覆盖矩阵头、条码、坐标和图像边界。逐样本报告与文件哈希已记录，独立在线目录读取仍待验收。

### 10x 官网无人值守验收（2026-11-04）

空目录仅用人类、胰腺、Visium HD 作为检索条件。独立命令行浏览器未能读取官网目录，批量报告记录 `access_failed`，无人值守端到端尚未通过。随后在交互式浏览器确认健康人胰腺的官方归档，单独实测下载中断与恢复。终止进程后，首个 8 MiB 分段的哈希和修改时间保持一致。恢复后的下载遇到一个 HTTP 分段错误，补取同版本缺段后离线重放了 2,105,540,608 字节，产生 0 次 HTTP 请求。原生 2 µm 的 6,680,593 个表达条码全部有坐标，矩阵头的观测数一致，映射到 600 × 597 的低分辨率 PNG 后无越界。验收范围为文件对应、矩阵头和图像边界。见 [胰腺逐样本验收](../examples/tenx_pancreas_acceptance/)。

10x 下载将已校验的分段保存到本地 `.archive-cache`，按归档来源、强 ETag、总长度和 SHA-256 校验，`find-spatial --resume` 重放缓存并请求缺少的区间。分段缓存仅留在本地。无强 ETag 的响应无法跨进程复用。

10x 缓存模式已由 DeepSeek 在 `05_Brain` 实跑。自动核对 E 盘图像、只获取所需配套文件，44,955 个细胞通过 12 项检查。见 [命令和实测记录](tenx_cache.md)。

已用 DeepSeek 总控跑通 10x 健康人脑皮层 `04_Brain`。从确切的官方 ZIP 只取配套小文件，复用已有图像，24,406 个细胞通过 16 项空间文件对应检查。见 [非肺实测](../examples/xenium_brain04/)。

v0.11 增加不限组织、物种的 GEO 搜索选项和样本级筛选，保留验证器覆盖边界。未指定 GSE/GSM 的人肺 Visium HD 试点读取 5 项研究的 10 个样本，选出 5 个；其中两个原生 2 µm GEO 包复用现有本地副本并通过验证，三个缺少本地配套文件。HEAD 可达性与本地文件状态分别记录。另盘点已有 Xenium 缓存的 13 类组织。独立公开来源的肺组织原生 16 µm 附件完成校验：158,361 个过滤表达条码均有坐标，换算后无越界；未读取完整计数矩阵。详见 [开放范围与本地复用](open_scope.md)、[实测摘要](../examples/open_scope/run_summary.json)。

v0.10 增加 Visium HD 原始 GEO 压缩包和无分辨率文件名的 HDF5/空间附件支持。明确 GSE 搜索可回退到按编号读取，并保留样本级筛选。真实人肺原生 2 µm 和从真实表达计数聚合的 16 µm 已通过统一入口。详见 [来源、准备与验证](visium_hd_archive.md)。

v0.9 已把 Visium HD 接入统一批量入口，按 2、8、16 µm 独立记录配套文件和验证结果。两个人肺 GEO 样本的 8 µm 公开文件实际通过核查。详见 [Visium HD 验证记录](visium_hd_batch.md)。

v0.8 已统一 Xenium 与传统 Visium 批量核查入口。真实混合批次通过 3 个肺 Visium 和 1 个肺 Xenium 样本，Visium 检查条码、矩阵头、坐标及低分辨率图像。详见 [混合批次结果](visium_batch.md)。

v0.7 已接通 GEO 筛选结果到 Xenium 批量文件核查。真实肺组织试点处理 7 个候选，本地模式记录 6 个缺少完整包，随后第 7 个样本通过 19 项检查。支持按单样本记录状态，导出微米与原始图像像素坐标。限额模式和模拟 HTTP 403 的边界见 [批处理与映射说明](xenium_batch.md)。

## v0.6 历史记录（2026-11-03）

当前阶段是“指定目标的真实空间数据流程已贯通，准备扩展批量候选”。Google Cloud / BigQuery 暂缓不影响此流程。

| 环节 | 已完成及证据 | 剩余边界 |
|---|---|---|
| 模型和原版总控 | 已有 DeepSeek 真实调用，复用固定上游总控和子 Agent | 不是所有上游模块均在线验证 |
| GEO 搜索与样本核查 | 已有空间候选查询、GSM 展开、逐样本证据核对；此前 31 个 Visium GSM 元数据完成 | 完整判断器仍限定人类肺组织 |
| 本地空间验证 | Xenium 真数据、19 项文件对应检查；v0.5 已有真实 Agent 调用 | Visium 尚未统一进入同一工具接口 |
| 搜索到文件的连接 | v0.6 从同一 GSM 的补充链接确定原始包，自动盘点本地文件、提取配套材料并生成 manifest | 目前指定 GSE/GSM，不是对全部候选自动批处理 |
| 同一样本完整真实流程 | GSE250346 / GSM7990538，四个工具依次执行，38.89 秒；4 个实时 GEO 请求、0 个缓存请求；19/19 检查通过 | 研究列出 45 个样本，只处理明确选定的 1 个 |
| 文件取得 | 自动复用 E 盘完整原始包约 933 MB；提取 6 个文件共约 68 MB | 新增受预算限制的下载代码，本轮未真实重新下载大包；远端字节身份未核对 |
| 核查与复现 | 101 项离线测试通过，依赖检查通过；保留来源、哈希、调用和失败状态 | 不是独立生物学准确率、召回率或分割金标准 |

完整证据与命令：[同一样本流程](pipeline.md)、[公开运行摘要](../examples/lung_pipeline/)、[v0.5 验证工具](local_validation_agent.md)。图像、矩阵和细胞级索引留在本地。
