# 开发路线

### 10x 官网无人值守验收（2026-11-04）

空目录仅用人类、胰腺、Visium HD 作为检索条件。独立命令行浏览器未能读取官网目录，批量报告记录 `access_failed`，无人值守端到端尚未通过。随后在交互式浏览器确认健康人胰腺的官方归档，单独实测下载中断与恢复。终止进程后，首个 8 MiB 分段的哈希和修改时间保持一致。恢复后的下载遇到一个 HTTP 分段错误，补取同版本缺段后离线重放了 2,105,540,608 字节，产生 0 次 HTTP 请求。原生 2 µm 的 6,680,593 个表达条码全部有坐标，矩阵头的观测数一致，映射到 600 × 597 的低分辨率 PNG 后无越界。验收范围为文件对应、矩阵头和图像边界。见 [胰腺逐样本验收](../examples/tenx_pancreas_acceptance/)。

10x 下载将已校验的分段保存到本地 `.archive-cache`，按归档来源、强 ETag、总长度和 SHA-256 校验，`find-spatial --resume` 重放缓存并请求缺少的区间。分段缓存仅留在本地。无强 ETag 的响应无法跨进程复用。

10x 缓存模式已由 DeepSeek 在 `05_Brain` 实跑。自动核对 E 盘图像、只获取所需配套文件，44,955 个细胞通过 12 项检查。见 [命令和实测记录](tenx_cache.md)。

已用 DeepSeek 总控跑通 10x 健康人脑皮层 `04_Brain`。从确切的官方 ZIP 只取配套小文件，复用已有图像，24,406 个细胞通过 16 项空间文件对应检查。见 [非肺实测](../examples/xenium_brain04/)。

v0.11 增加不限组织、物种的 GEO 搜索选项和样本级筛选，保留验证器覆盖边界。未指定 GSE/GSM 的人肺 Visium HD 试点读取 5 项研究的 10 个样本，选出 5 个；其中两个原生 2 µm GEO 包复用现有本地副本并通过验证，三个缺少本地配套文件。HEAD 可达性与本地文件状态分别记录。另盘点已有 Xenium 缓存的 13 类组织。独立公开来源的肺组织原生 16 µm 附件完成校验：158,361 个过滤表达条码均有坐标，换算后无越界；未读取完整计数矩阵。详见 [开放范围与本地复用](open_scope.md)、[实测摘要](../examples/open_scope/run_summary.json)。

v0.10 增加 Visium HD 原始 GEO 压缩包和无分辨率文件名的 HDF5/空间附件支持。明确 GSE 搜索可回退到按编号读取，并保留样本级筛选。真实人肺原生 2 µm 和从真实表达计数聚合的 16 µm 已通过统一入口。详见 [来源、准备与验证](visium_hd_archive.md)。

v0.9 已把 Visium HD 接入统一批量入口，按 2、8、16 µm 独立记录配套文件和验证结果。两个人肺 GEO 样本的 8 µm 公开文件实际通过核查。详见 [Visium HD 验证记录](visium_hd_batch.md)。

v0.8 已统一 Xenium 与传统 Visium 批量核查入口。真实混合批次通过 3 个肺 Visium 和 1 个肺 Xenium 样本，Visium 检查条码、矩阵头、坐标及低分辨率图像。详见 [混合批次结果](visium_batch.md)。

v0.7 已接通 GEO 筛选结果到 Xenium 批量文件核查。真实肺组织试点处理 7 个候选，本地模式记录 6 个缺少完整包，随后第 7 个样本通过 19 项检查。支持按单样本记录状态，导出微米与原始图像像素坐标。限额模式和模拟 HTTP 403 的边界见 [批处理与映射说明](xenium_batch.md)。

## 最新进度：v0.6（2026-11-03）

当前阶段是“指定目标的真实空间数据流程已贯通，准备扩展批量候选”。Google Cloud / BigQuery 暂缓不影响此流程。

| 环节 | 已完成及证据 | 剩余边界 |
|---|---|---|
| 模型和原版总控 | 已有 DeepSeek 真实调用，复用固定上游总控和子 Agent | 不是所有上游模块均在线验证 |
| GEO 搜索与样本核查 | 已有空间候选查询、GSM 展开、逐样本证据核对；此前 31 个 Visium GSM 元数据完成 | 完整判断器仍限定人类肺组织 |
| 本地空间验证 | Xenium 真数据、19 项文件对应检查；v0.5 已有真实 Agent 调用 | Visium 尚未统一进入同一工具接口 |
| 搜索到文件的连接 | v0.6 从同一 GSM 的补充链接确定原始包，自动盘点本地文件、提取配套材料并生成 manifest | 目前指定 GSE/GSM，不是对全部候选自动批处理 |
| 同一样本完整真实流程 | GSE250346 / GSM7990538，四个工具依次执行，38.89 秒；4 个实时 GEO 请求、0 个缓存请求；19/19 检查通过 | 研究列出 45 个样本，只处理明确选定的 1 个 |
| 文件取得 | 自动复用 E 盘完整原始包约 933 MB；提取 6 个文件共约 68 MB | 新增受预算限制的下载代码，本轮未真实重新下载大包；远端字节身份未核对 |
| 核查与复现 | 101 项离线测试通过，依赖检查通过；保留来源、哈希、调用和失败状态 | 不是独立生物学准确率、召回率或分割金标准 |

完整证据与命令：[同一样本流程](pipeline.md)、[公开运行摘要](../examples/lung_pipeline/)、[v0.5 验证工具](local_validation_agent.md)。图像、矩阵和细胞级索引留在本地。

### 下一步顺序

1. 把已有候选筛选结果逐一交给新文件准备阶段，扩展少量真实样本，记录缺失、受限、失败及可恢复状态。
2. 对可访问公开资产验证下载路径，并完善多包消歧、批量任务与文件准备阶段的断点续跑。
3. 统一 Xenium / Visium 验证入口；分别处理 cell、spot、bin 和不同文件版本。
4. 将组织判断从肺试点参数化，再建立经过研究者复核的独立测试集和原版/空间版本对照。
5. 条件允许时补 BigQuery、术语向量库及更多上游模块；不作为当前空间流程前提。
