# v0.2：样本核查、Agent 对照与空间文件检查

本版复用固定版本 SRAgent 的模型工厂、NCBI Agent 与 LangGraph，增加空间任务工具，不训练新语言模型。真实模型对照需本机配置 OpenAI API 凭证；没有凭证时结果明确标为未运行。

## 25 条核查开发样本

`evaluation/lung_spatial_development.json` 保存来自 9 个 GEO 研究的 25 条 GSM 样本、出处及暂定参考标签。17 条为人类肺空间样本，5 条为非肺（右心室、喉/下咽），3 条来自空间相关研究但样本自身描述普通 Chromium 单细胞/多组学，无法确认为空间测量。

材料由助手依据原始样本字段整理，状态为 `assistant_prepared_pending_human_review`。它是待研究者复核的开发集，不是独立人工金标准或留出测试集。规则在这批材料上与暂定参考标签相符，不代表泛化准确率。当前没有真实混合样本，混合情况只用虚构单元测试覆盖。

数据过滤无关临床特征及联系人字段。参考标签与模型输入分开保存，不传给模型。核查者仍需复查组织、平台和样本归属，补充未知与真实混合案例。

## 四类判断与证据

`eligible`：样本有明确人类、肺组织和空间平台证据。`non_lung`：样本明确为其他器官。`mixed`：组织、平台或物种出现混合/冲突。`unknown`：缺少可确认符合条件的证据，包括普通单细胞样本没有空间测量证据。

规则使用样本自己的 tissue/organ、source_name、organism 与实验协议，不从研究摘要或仅提及肺的标题补组织。模型必须返回相同 GSM 身份、合法标签与原文引文，引用其他样本、研究页、不存在的字段或捏造引文都会被拒绝。引文检查通过仍不保证语义判断正确。

## 三路径对照

- `rules`：样本级规则，不调用模型。
- `original_agent`：直接调用固定版本上游 `create_ncbi_fetch_agent`。
- `spatial_agent`：复用上游模型工厂、NCBI Agent 和 LangGraph，新增冻结样本资料读取与空间规则检查工具。

这里的原版对照明确选用原版的 NCBI 查询 Agent 子模块，不是原版全部 Entrez/BigQuery/Sequences 多层系统。因此不能把结果推广为优于或复现了完整 SRAgent。

使用相同样本编号、输入材料和显式选择的模型。原版 Agent 仍可访问实时公开资料，扩展 Agent 有额外工具并可能调用更多次模型，因此不是完全冻结证据、相同调用预算的因果对照。模型用量及费用尚未测得，不估造数值。

```bash
python run.py doctor
python run.py benchmark --methods rules --out outputs/v02/rules_benchmark.json
```

默认三路径遇到缺少凭证时，规则仍运行，模型保存 `not_run_missing_api_key`，分数为 null，以退出码 2 表示未全部完成。真实付费运行必须显式指定 `--limit`，先从 1 条开始。超时与步骤上限不是金额上限。

## OpenAI 配置

按 [OpenAI 官方认证说明](https://developers.openai.com/api/reference/overview)，密钥通过本机环境变量或密钥管理提供，不写入仓库。

在独立环境安装：

```powershell
python -m venv .venv-agent
.\.venv-agent\Scripts\python.exe -m pip install -e ".[agent]" -c configs/agent-constraints.txt
.\.venv-agent\Scripts\python.exe run.py doctor
```

本机启动脚本隐藏输入密钥，不写入命令历史或永久设置。已有 `OPENAI_API_KEY` 则直接使用；模型 ID 必须由用户明确选择，并拥有该模型访问权限，上游也需支持它。

推荐直接使用 Python 隐藏输入入口，无需更改 PowerShell 脚本执行策略：

```powershell
.\.venv-agent\Scripts\python.exe scripts/run_agents.py --model YOUR_MODEL_ID --limit 1
```

只有在本机交互终端且尚无环境变量时才提示输入密钥；非交互环境不会退回明文输入。以下 PowerShell 脚本作为另一种入口：

```powershell
.\scripts\run_agents.ps1 -Model YOUR_MODEL_ID -Limit 1 -Python .\.venv-agent\Scripts\python.exe
```

项目提供专用模型配置，避免继承上游生产数据库及默认 Flex 设置。若用户显式设置 `DYNACONF_SETTINGS_PATH`，则使用该设置文件。

兼容性约束用于缩小旧上游依赖与新发布包之间的解析范围，不是作者官方锁文件。Windows 模型命令在应用入口使用 truststore 验证系统证书，保留 TLS 验证；此设置不改变系统信任库。

## 初步空间一致性检查

公开胎肺 Visium 样本 GSM8217624 的四个小型配套文件共 541,943 字节：条码、坐标、比例因子、低分辨率图像。未下载矩阵或高分辨率图。

3,949 个条码均在 4,992 行位置表中找到，缺失 0；3,949 个组织内点缩放后都落在 530 × 600 图像范围内。没有检查表达矩阵列数；图像仅检查 PNG 头部尺寸。

```bash
python run.py check-visium --barcodes BARCODES --positions POSITIONS --scalefactors SCALEFACTORS --lowres-image LOWRES_PNG --out outputs/spatial/check.json
```

支持 gzip、旧版无表头和新版 positions CSV，可选 `--matrix` 只检查 Matrix Market 头部列数。每个文本最多一百万行，不是 Visium HD 全量验证器。

这不证明同一物理切片/供者、组织细节配准、细胞分割或病理标注正确。坐标按文件全分辨率像素约定解释，不推断微米尺度。详细结果和下载校验和留在本机 `outputs/v02`，不提交原始数据。
